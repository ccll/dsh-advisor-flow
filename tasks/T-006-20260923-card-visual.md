# 设置卡视觉对齐宿主插件卡

状态: completed
关联: R-02-001（GUI 面）
风险等级: standard

## 背景与目标

东家实测反馈四点视觉问题：① 卡片默认展开（应默认折叠，与其他插件卡一致）；② 折叠态显示「已折叠——点击头部展开配置」提示行（应去除）；③ 折叠/展开图标不一致（应同款图标旋转切换，对齐宿主 chevron 形态）；④ 展开态表单排版参差不齐（应对齐 dsh-advisor 卡的表单排版：fieldset/field/fieldLabel/input/selectInput/footer 层级与间距）。

## 差距评估

- render.js 当前默认展开、有提示行、'▾' 字符图标、表单布局松散。
- 参照系：~/.dsh/profiles/web/node_modules/dsh-advisor/lib/client.js 的 advisor-card.module.css（CSS 变量 --dsw-alias-*、card/header/name/description/chevron/body/form/checkboxRow/field/fieldLabel/input/selectInput/footer/notice 全套）。

## 收敛方案

- render.js 结构与样式对齐 dsh-advisor 卡形态（类名前缀 advisorflow_，CSS 注入机制不变）：
  - 默认折叠（open 默认 false；error 态强制展开保留）；
  - 删除折叠提示行；
  - chevron 用内联 SVG（与 dsh-advisor 同路径 M3 4.5L6 7.5L9 4.5），旋转过渡切换折叠/展开——两态同图标；
  - 表单排版：checkboxRow（启用）、field 三列（provider/model/effort 下拉保留既有联动）、四门 fieldset+legend、privacy fieldset、footer 右对齐按钮组、回执/错误文案样式齐全。
- 逻辑层（catalog 联动/unwrap/三态回执/持久写）零改动；`npm run build:client` 重建产物随提交。

## 测试计划

- 真实验收：staging headless 截图（折叠态 + 展开态）东家目验。
