# C-032 介入强度缺省回归 soft（废弃 C-022 的缺省 hard 裁定）

日期: 2026-10-15

#### 上下文
C-022 为开箱即获收口评审裁定 mode 缺省 hard（东家 2026-10-09），PRD 愿景段与 R-02-001/AC-04 随之承诺缺省硬模式并列为 pi 偏离项。0.2.0 生产实测后，东家 2026-10-15 指令改默认为 soft 模式：开箱行为应温和（守则建议），强制收口评审属重手段，应显式选择而非默认。

#### 决策
`DEFAULT_INTERVENTION_MODE` 改 `'soft'`；PRD 愿景段与 AC-04、SOLUTION 设置命名空间条目同步改缺省软模式。C-022 仅废弃其缺省 hard 裁定，其余内容（控件置顶等）继续有效。

#### 被否方案及原因
- 维持缺省 hard：与东家最新裁定正面冲突。
- 保留 hard 缺省、在卡片默认选中 soft：配置真值与展示默认两处漂移，describe 投影与运行时归一不一致，违背单点缺省（解析层单点缺省纪律）。

#### 影响面
R-02-001 / 配置与状态服务 · R-01-009 / 门控服务（T-032）
