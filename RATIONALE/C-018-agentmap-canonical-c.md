# C-018 AgentMap 工作系统升级至 2026-10-06 canonical：C-016 豁免随之废止

日期: 2026-10-08

#### 上下文
框架模板（agentmap-bootstrap，2026-10-06）演进三组能力：EARS 模态词后缀校准、RATIONALE 措辞层修订语义指纹门禁、写作风格检查套件。本仓库校验器与模板双向分叉：仓库侧独有 C-016 豁免套件（is_commit_evidence_repair 两轴挂接与自测）与 T-010 的 migration 软化（悬空锚点降级警告）。bootstrap 将 managed 文件重置为 canonical 后，豁免与软化面临去留裁决。实测基线：升级前后 self-test、--report、pre-commit、pre-push 全部通过（anchor-coverage 68/68、expected-fail 230 实跑 0 失败），且当前 0 个未推送提交——豁免在现状下没有保护对象。

#### 决策
采纳 canonical 全量语义；C-016 豁免维持废止——不回移植仓库副本、不上移框架模板；T-010 的 migration 软化一并废止，migration 模式下未知锚点回归硬错误。本条废弃 C-016。

#### 被否方案及原因
- 回移植豁免到仓库副本：延续「每次框架升级重复回移植」的已记账残余风险；为假想需求保留分叉点，与豁免现状无保护对象的事实不符。
- 上移豁免至框架模板并对所有项目默认生效：把单一项目裁决扩展为全局默认语义，超出本次升级边界，且需写入框架资产目录，应另立决策。
- opt-in（CONVENTIONS 声明启用豁免）：同样需要改动框架模板实现，引入参数位与实现分支，复杂度先于真实需求。

#### 影响面
校验器实现与自测；无对应 PRD 需求 R-ID 与产品子系统规范名，承 C-016 复审备注确立的校验器过程基建格式豁免先例；无执行 task（东家裁定仅 RATIONALE 记账）。残余风险：未来 amend 销毁终态证据引用的提交时，终态不可变与证据可达两规则将重新互斥，届时以东家重新裁定为唯一合法出口，本条为该场景的记账锚点。

补充（东家裁定，同日会话）：分叉差异全文为工作机本地临时归档，不随仓库分发、不入库，不承诺 clone 可达；差异要点已由本条上下文与升级提交正文承载。
