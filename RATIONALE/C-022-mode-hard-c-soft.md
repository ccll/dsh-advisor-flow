# C-022 mode 缺省 hard 与设置卡控件位置：废弃 C-021 的缺省 soft 裁定

日期: 2026-10-09

#### 上下文
T-020 交付后东家在 web 设置卡实测介入强度配置。
- 东家裁定：介入强度是 advisor 行为的总纲档位。
- 控件位置应紧随总开关（enabled）之后、高于其余全部选项。
- 缺省值应为 hard，开箱即获每回合收口评审。
- 缺省导向不再取「与 pi 开箱行为一致」。
- 缺省值属可观察行为变更，走全链（T-021）。

#### 决策
- `mode` 缺省由 `soft` 改为 `hard`。
- 设置卡中介入强度控件移至总开关紧下、高于其余选项。
- 本条废弃 C-021 决策中的「缺省 soft」裁定。
- C-021 其余裁定全部维持，逐项如下。
  - 软硬语义、按裁决分流、去重、fail-open 维持。
  - failureMode 不适用收口缝维持。
  - 压缩提醒随软模式维持。

#### 被否方案及原因
- 维持缺省 soft：与东家「开箱即硬」裁定直接冲突。
- 维持缺省 soft 的代价：软模式降级为显式选择项，设置卡仍可切回。
- 控件置于 failureMode 之后（T-020 现状）：介入强度语义高于处置细节。
- 控件位置实测裁决：东家定位于总开关紧下。

#### 影响面
R-01-009/AC-02；R-02-001/AC-04（T-021）。
