# C-030 配置卡平铺常开并删除用户级启用开关（启用状态改配置派生）

日期: 2026-10-14

#### 上下文
dsh 0.2.0 插件管理页为每插件提供独享配置详情页，且页面自带插件级启停开关；advisor-flow 设置卡沿用 0.1.x 多卡共享设置页时代的默认折叠交互与用户级 `enabled` 开关。东家实测后判定：折叠在独享页面只剩一次多余点击且藏内容（已引发「详情页无配置项」误读）；启停语义与宿主插件开关重叠，会话级静音已有 `/advisor off`。

#### 决策
配置卡平铺常开（保留静态标题行与未保存徽标，去 chevron 与展开态）；删除用户级 `enabled` 开关，咨询功能启用状态改为配置派生——`advisor.provider` 与 `advisor.model` 齐备即启用，任一缺失即禁用且状态可查询；settings.yaml 遗留 `enabled` 键告警并忽略；未配置时卡片顶部呈现提示横幅。

#### 被否方案及原因
- 保留折叠交互：独享配置页无共存卡片，折叠无信息密度收益，反增一次点击并隐藏全部字段。
- 保留软开关（装载但不出手）：与宿主插件级开关语义重叠，两处真值易漂移；会话级静音已由 `/advisor off` 承载。
- 仅 yaml 保留 `enabled`、卡片隐藏：同一配置两个面不一致，键清单漂移。

#### 影响面
R-02-001 / 配置与状态服务 · web 设置卡（T-031）
