# C-013 三个开口项的东家 deferral 裁决（Scout 接线补齐，其余记档）

日期: 2026-09-25

#### 上下文
黄金标准完成判定前，独立代码审核与顾问（adv-19）指出三个开口项需与 dsh 无法承载项同等级别的裁决：Scout 引擎接线、getCwd 会话工作区缝、tool-result-cap 默认行数。staging 实弹五处真断缝的检出史使接线类缝隙的先验概率升高，被动挂账低估警示。
#### 决策
东家裁决：Scout 引擎接线在目标内补齐（实弹验证）；getCwd 多会话缝与 tool-result-cap 默认行数 200 以联调核定项记档随目标关闭。
#### 被否方案及原因
三项全部记档延期——否：Scout 接线为 dsh 可承载面且与其余已发现断缝同类，挂账将保留同缺陷类先验；接线后实弹核定成本可控。getCwd 记档——多会话工作区解析需宿主侧缝形态实证，超出本目标可验证范围。
#### 影响面
R-01-006 素材构成 · 素材装配器/Scout 策展（T-014 已闭，接线以本决策补全）
